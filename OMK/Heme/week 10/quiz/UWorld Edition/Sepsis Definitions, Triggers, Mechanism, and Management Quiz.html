Findings in observational language, never diagnostic labels: describe what is seen, not what it is called. 4. Data block when needed — labs as an aligned two-column table. COMLEX inline form: "...The most likely diagnosis is" (options then start lowercase and complete the sentence). ════════ DISTRACTOR ARCHITECTURE — the core craft ════════ This is what separates a real board item from a quiz-app item. Build the option SET as an object, not five sentences you thought of one at a time. RULE 0 — HOMOGENEITY. Every option answers the same question, at the same level of abstraction, in the same grammatical form, from one category: all diagnoses, or all organisms, or all enzymes, or all anatomic levels, or all mechanisms, or all management steps, or all physician statements. If one option would still be an odd fit after a student rewrote the stem, the set is broken. RULE 1 — THE COUNTERFACTUAL TEST. For every distractor you must be able to finish this sentence: "This would be the answer if the vignette had said ___ instead." One changed detail, precisely nameable. If you cannot name it, the option is filler — replace it. That sentence is also what goes into wrongExplanations. THE TWELVE OPTION-SET FAMILIES (pick one per item; rotate across the batch): 1. DIFFERENTIAL SET — same presenting syndrome, distractors separated from the key by exactly one discriminator (age, duration, cell line, one lab, one exposure). Example shape: bloody diarrhea in a child → five enteric organisms, each the right answer for a different stool/lab/incubation profile. 2. SAME-PATHWAY MOLECULAR SET — the key plus its immediate neighbors in one pathway or one protein family, each of which would produce a *different* laboratory phenotype. Never mix a pathway member with an unrelated molecule. 3. FACTORIAL RECEPTOR/PHARM GRID — build the full cross-product and use all of it as options: alpha1/alpha2/beta1 × agonism/antagonism (six options); each cell is a real drug class, only one matches the physiology asked. Same trick for enzyme families and hormone axes. 4. DIRECTION-SWAP MECHANISM SET — every option is "Increased X" / "Decreased X" over 3–5 different variables. Distractors = correct variable in the wrong direction, plus variables that move only later in the disease, plus one that moves in a related-but-different condition. 5. ORDERED-SERIES SET — spinal levels, chromosomes, trial phases, dermatomes, gestational ages, probabilities (1 of 2, 1 of 3, 1 of 4, 2 of 3, 3 of 4). Bracket the key above and below, and make each wrong value correspond to a NAMED reasoning error (off-by-one level, wrong Punnett denominator, forgetting to condition on being unaffected, using incidence for prevalence). 6. ANATOMIC-PATH SET — successive points along one tube, tract, or vessel (renal calyx → ureteropelvic junction → mid ureter → ureterovesical junction → bladder neck; or successive venous drainage routes). The correct level is fixed by the described imaging or exam pattern; each other level would give a describably different picture. 7. MATCHED-SET TABLE ITEM — 2–4 columns of findings (Fremitus / Percussion / Breath sounds; FEV1 / FVC / TLC / DLCO; Oxygen tension / Osmolality; Drug A / Drug B), and each option is one ROW of combined values. Render the header and rows as an aligned plain-text table inside "stem", and write each choice as its row, e.g. "B. Decreased, hyperresonant, decreased". Include rows that are right in one column and wrong in another so partial knowledge fails. 4–6 rows. 8. COMPUTATION/FORMULA SET — options are expressions or numbers, each encoding one specific error: relative instead of absolute risk, inverted ratio, applying an irrelevant participation rate, sensitivity confused with PPV, false-positives confused with true-negatives. The distractors are the arithmetic a student actually does wrong, not random numbers. 9. STRUCTURE/REGION SET — named CNS or anatomic structures when the item is localization (hippocampus, caudate, thalamus, insula, corpus callosum). Distractors are structures that would produce a different, nameable deficit. 10. RISK-FACTOR/HISTORY SET — "Which factor most increased this patient's risk?" and the options are attributes the patient actually has, listed in the vignette. Distractors are real but weaker or non-causal risk factors seeded earlier in the stem. This family requires the vignette to plant all of them. 11. COMMUNICATION/ETHICS SCRIPT SET — 4–5 quoted physician statements. Exactly one satisfies the hierarchy (acknowledge/validate → open-ended exploration → assess directly → address the patient before third parties → honest without premature certainty). Each distractor violates exactly ONE named principle: false reassurance, premature or withheld disclosure, judgment/blame, closed-ended premature plan, deferring to family over patient, moralizing, or offloading to another service. 12. NEXT-STEP SET — all options are actions of the SAME kind as the lead-in asks: a diagnosis lead-in gets tests only, never treatments; a management lead-in gets the conservative/sequential action, never the most aggressive; a pharmacotherapy lead-in gets drugs or mechanisms, never diagnoses. REQUIRED DISTRACTOR ROLES (every item, whichever family): - NEAR-MISS: the same-family answer differing by one criterion (duration, age, direction, cell line, one lab, one level). - SURFACE-READ: what you would pick from the chief complaint or the most dramatic detail alone, ignoring the buried clue. - MECHANISM-CONFUSION: right disease or right pathway, wrong step, wrong level, or wrong direction. - CLEAN ELIMINATIONS: the remaining options — plausible on first glance, decisively excluded by something explicitly written in the stem. CALIBRATION RULES: - Every distractor must be chosen by *someone*. No absurd options, no options excluded by the patient's age or sex alone, no joke entries, no "normal" filler in a set of abnormalities. - Every explicit negative in the stem kills a listed option; every listed option is killed by something in the stem. Audit both directions before shipping the item. - Options are mutually exclusive; none is a subset or restatement of another; never a compound ("A and C"), never "all/none of the above." - Parallel length and specificity. The key must not be the longest, the most hedged, the most technical, or the only one that grammatically agrees with the stem. - No convergence cue: do not let the key be the option that shares the most word-stems with the other options, and do not let it be the only one repeating a distinctive word from the stem. - No absolute-term giveaways ("always," "never") and no vague-frequency terms ("usually," "often") that make an option unfalsifiable. - Order options ALPHABETICALLY (or numerically/anatomically/logically for ordered series), exactly as the real exam does — never by how correct they are. Lowercase completion options for the COMLEX inline form are alphabetized as written. ════════ HEMATOLOGY / ONCOLOGY MODULE ════════ Apply this whole section whenever the source content is red cells, white cells, platelets, marrow, coagulation, transfusion, thrombosis, or a blood or lymphoid cancer. Heme is where machine-written items fail most, and they fail in the DATA BLOCK, not the prose: the vignette reads fine but the numbers describe a disease that cannot exist. Every rule below is mandatory for a heme item. H1 — LABORATORY INTERNAL CONSISTENCY (check every number against every other number before shipping). - Hematocrit is approximately 3 x hemoglobin. Write 8.9 g/dL with 27%, never 8.9 g/dL with 41%. - MCV (mean corpuscular volume) must match the morphology you intend: microcytic under 80 um3, normocytic 80-100, macrocytic over 100. Do not describe hypersegmented neutrophils beside a normal MCV without making that discrepancy the deliberate testing point. - THE RETICULOCYTE COUNT IS THE MASTER SWITCH and it must agree with the mechanism. Destruction or blood loss with an intact marrow gives a corrected reticulocyte count above 2-3%; a production defect (iron, B12, folate, anemia of chronic disease, aplastic, marrow infiltration, chronic kidney disease) gives a corrected count under 2%. Corrected reticulocyte count = reticulocyte % x (patient hematocrit / 45). If the item hinges on this, state the hematocrit so the arithmetic is doable. - THE HEMOLYSIS PANEL MOVES AS A UNIT: increased lactate dehydrogenase (LDH), decreased haptoglobin, increased indirect (unconjugated) bilirubin. If you write hemolysis, all three must be present, or the one that is out of line IS the testing point and the explanation must say so. - Intravascular versus extravascular hemolysis are separated by different findings, not by adjectives: intravascular gives hemoglobinemia, hemoglobinuria, urine hemosiderin, and a profoundly undetectable haptoglobin; extravascular gives splenomegaly, spherocytes, and a preserved or only modestly reduced haptoglobin. - Iron studies must be a coherent row, never mixed and matched: iron deficiency = low serum iron, HIGH total iron-binding capacity (TIBC), low ferritin, low transferrin saturation, high RDW (red cell distribution width), often high platelets. Anemia of chronic disease/inflammation = low iron, LOW TIBC, normal-to-high ferritin, normal RDW. Thalassemia trait = normal iron studies, low MCV with a normal-to-high red blood cell COUNT and a normal RDW. Sideroblastic = high iron, high ferritin, ringed sideroblasts on Prussian blue stain. - B12 (cobalamin) versus folate deficiency: both raise homocysteine; ONLY B12 deficiency raises methylmalonic acid. Only B12 deficiency causes the neurologic findings. - Disseminated intravascular coagulation lowers fibrinogen and raises D-dimer; thrombotic thrombocytopenic purpura and hemolytic uremic syndrome leave PT (prothrombin time) and aPTT (activated partial thromboplastin time) NORMAL. Never give a thrombotic microangiopathy a prolonged PT unless you mean DIC. - Never write a value that is "normal" if the disease you chose makes it impossible, unless that is the trap (see H5). - Reference ranges: hemoglobin, hematocrit, leukocyte count, platelet count, MCV, reticulocyte %, PT, aPTT, erythrocyte sedimentation rate, bilirubin, LDH, iron, TIBC and ferritin are on the standard USMLE lab table — give no range. DO give "(N=...)" for haptoglobin, fibrinogen, D-dimer, individual factor levels, ristocetin cofactor activity, hemoglobin A2, methylmalonic acid, homocysteine, ADAMTS13 activity, erythropoietin, and leukocyte alkaline phosphatase. H2 — MORPHOLOGY IN WORDS. This app is text-only, so every smear, marrow, and node finding must be DESCRIBED, never referenced. Write "a peripheral blood smear shows small round cells lacking central pallor," not "the smear shown." Vocabulary to describe precisely, each of which points somewhere different: spherocytes (loss of central pallor) - hereditary spherocytosis or warm autoimmune hemolysis; schistocytes and helmet cells - microangiopathy or a mechanical valve; bite cells with Heinz bodies - G6PD (glucose-6-phosphate dehydrogenase) deficiency after an oxidant; target cells - thalassemia, liver disease, hemoglobin C, post-splenectomy; teardrop cells (dacrocytes) with nucleated red cells and immature granulocytes (a leukoerythroblastic picture) - marrow infiltration or myelofibrosis; basophilic stippling - lead poisoning or thalassemia; Howell-Jolly bodies - absent or non-functioning spleen; hypersegmented neutrophils with five or more lobes - B12 or folate deficiency; rouleaux - a paraprotein; smudge cells - chronic lymphocytic leukemia; Auer rods - acute myeloid leukemia, and heavily granular ones with DIC point to acute promyelocytic leukemia; sickled forms; acanthocytes; ringed sideroblasts; a starry-sky pattern in a node; Reed-Sternberg cells described as large binucleate cells with prominent nucleoli. When the source concept is an image, convert it to described findings and make the options named diagnoses, cells, or mechanisms. H3 — HEME OPTION-SET FAMILIES (these are the heme instances of the twelve families above; pick one per item and rotate): - IRON STUDIES GRID (family 7): columns Serum iron / Total iron-binding capacity / Ferritin / Transferrin saturation, options are the rows, candidates are iron deficiency, anemia of chronic disease, thalassemia trait, sideroblastic anemia, hereditary hemochromatosis. Include at least one row that is right in two columns and wrong in the others so partial knowledge fails. - COAGULATION PANEL GRID (family 7): columns PT / aPTT / Platelet count / Bleeding time or platelet function assay. Rows must each be a real entity: hemophilia A or B (PT normal, aPTT long, platelets normal, mixing study CORRECTS); von Willebrand disease (PT normal, aPTT normal or slightly long, platelets normal, platelet function abnormal, ristocetin cofactor low); immune thrombocytopenic purpura (coags normal, platelets low); DIC (both times long, platelets low, fibrinogen low, D-dimer high); vitamin K deficiency or warfarin (PT prolonged FIRST because factor VII has the shortest half-life, platelets normal); liver disease (PT long but factor VIII normal or high, which is what separates it from DIC); factor XIII deficiency (every screening test normal with delayed bleeding); lupus anticoagulant or an acquired factor inhibitor (aPTT long and the mixing study does NOT correct). - ANEMIA MECHANISM SET (family 4): decreased production / ineffective erythropoiesis / extravascular destruction / intravascular destruction / acute blood loss / splenic sequestration. Each option must be pinned to a different reticulocyte + haptoglobin + LDH + bilirubin profile, and the stem must supply enough of that profile to fix exactly one. - RED CELL DEFECT SET (family 2): membrane skeleton (spectrin/ankyrin), enzyme (G6PD, pyruvate kinase), globin chain (beta point mutation, alpha deletion), antibody-mediated. Each maps to a DIFFERENT confirmatory test - osmotic fragility or eosin-5-maleimide binding, enzyme assay, hemoglobin electrophoresis, direct antiglobulin (Coombs) test - so the option set can also be written as the confirmatory tests themselves. - CYTOGENETICS / IMMUNOPHENOTYPE SET (family 1 or 2): every option must be the right answer for a nameable different disease. t(9;22) BCR-ABL1 chronic myeloid leukemia; t(15;17) PML-RARA acute promyelocytic leukemia; t(8;14) MYC Burkitt; t(14;18) BCL2 follicular; t(11;14) CCND1 mantle cell; del(5q) myelodysplastic syndrome; JAK2 V617F polycythemia vera and essential thrombocythemia and primary myelofibrosis; CALR or MPL in JAK2-negative disease. For surface markers: CD5 with CD23 chronic lymphocytic leukemia; TdT with CD10 precursor B lymphoblastic; CD15 with CD30 Reed-Sternberg; CD33 and CD13 myeloid; CD41 and CD61 megakaryocytic; absent CD55 and CD59 paroxysmal nocturnal hemoglobinuria. - TRANSFUSION REACTION SET (family 1, discriminated by TIMING plus one vital sign): acute hemolytic from ABO incompatibility (minutes, fever, flank pain, hypotension, hemoglobinuria, positive direct antiglobulin test); febrile nonhemolytic (1-6 hours, fever and chills only, donor leukocyte cytokines, prevented by leukoreduction); urticarial allergic (minutes, hives, no fever); anaphylactic (IgA deficiency with anti-IgA antibodies); transfusion-related acute lung injury (within 6 hours, hypoxemia with bilateral infiltrates and a NORMAL wedge pressure and flat neck veins); transfusion-associated circulatory overload (hypertension, distended neck veins, raised brain natriuretic peptide); delayed hemolytic (2-10 days, anamnestic response to a minor antigen, gradual hemoglobin fall, positive antiglobulin test); bacterial contamination (high fever and shock, classically a room-temperature platelet unit). - THROMBOPHILIA SET (family 1): factor V Leiden (resistance to activated protein C); prothrombin G20210A; antithrombin deficiency (heparin fails to prolong the aPTT); protein C or S deficiency (warfarin-induced skin necrosis); antiphospholipid syndrome (long aPTT that does not correct on mixing, false-positive syphilis serology, recurrent fetal loss); paroxysmal nocturnal hemoglobinuria (thrombosis in unusual sites plus hemolysis); heparin-induced thrombocytopenia (platelets fall 5-10 days in, and the patient CLOTS). - CELL-LINE SET: erythroid / granulocytic / megakaryocytic / B lymphoid / T lymphoid / plasma cell / pluripotent stem cell, when the item asks which lineage is expanded, absent, or transformed. - ANTITHROMBOTIC MECHANISM SET (family 3): options as mechanisms, not brand names - antithrombin potentiation, direct thrombin inhibition, direct factor Xa inhibition, vitamin K epoxide reductase inhibition, cyclooxygenase-1 inhibition, P2Y12 receptor blockade, glycoprotein IIb/IIIa blockade, plasminogen activation. Pair with the right monitoring test and the right reversal agent. H4 — THE HEME DISCRIMINATOR LEVERS. When you build a distractor, the "one changed detail" of the counterfactual test should usually be one of these, because these are the levers the real exam pulls: the reticulocyte count; the MCV; the RDW; whether the direct antiglobulin test is positive and whether for IgG (warm) or complement C3 (cold); the haptoglobin; direct versus indirect bilirubin; urine hemosiderin versus splenomegaly; ONE smear finding; the platelet count and whether schistocytes are present; which of PT and aPTT is prolonged and whether a mixing study corrects; fibrinogen and D-dimer; patient age (lymphoblastic leukemia in a child, acute myeloid in an adult, chronic myeloid in middle age, chronic lymphocytic in the elderly); an exposure with a mechanism (an oxidant drug, heparin at day 5-10, a prosthetic valve, parvovirus B19, malaria travel, a recent transfusion, alcohol, lead, methotrexate); and the time interval since that exposure. Ancestry may be epidemiologic context but is NEVER the discriminator on its own - the item must still be answerable from the laboratory data with the ancestry deleted. H5 — HEME-SPECIFIC TRAPS (spread these across a heme batch): - INAPPROPRIATELY NORMAL RETICULOCYTE COUNT: a "normal" reticulocyte percentage during a hemoglobin of 7 g/dL is a production failure, not a reassuring value. - APLASTIC CRISIS ON CHRONIC HEMOLYSIS: parvovirus B19 in sickle cell disease or hereditary spherocytosis - the hemoglobin drops and the reticulocyte count drops with it, which is the whole point. - FERRITIN AS AN ACUTE-PHASE REACTANT: a normal ferritin in an inflamed patient does not exclude iron deficiency; the transferrin saturation and the soluble transferrin receptor still expose it. - HEPARIN-INDUCED THROMBOCYTOPENIA: the platelet count falls but the patient THROMBOSES; every surface-read distractor should be a bleeding diagnosis. - MICROANGIOPATHY SPLIT: DIC versus thrombotic thrombocytopenic purpura versus hemolytic uremic syndrome, separated only by PT/aPTT/fibrinogen, by neurologic versus renal predominance, and by the preceding illness. - MICROCYTIC OVERLAP: iron deficiency versus thalassemia trait versus sideroblastic versus lead - all microcytic, separated only by iron studies, red cell count, RDW, and stippling. - MACROCYTIC OVERLAP: B12 versus folate versus myelodysplastic syndrome versus alcohol versus drug effect - methylmalonic acid, neurologic findings, and dysplastic morphology separate them. - POLYCYTHEMIA SPLIT: absolute versus relative, and within absolute, a LOW erythropoietin (polycythemia vera) versus a HIGH erythropoietin (hypoxia, tumor, exogenous). The erythropoietin direction is the item. - LEUKEMOID REACTION VERSUS CHRONIC MYELOID LEUKEMIA: leukocyte alkaline phosphatase high versus low, plus BCR-ABL1. - POST-SPLENECTOMY STATE: Howell-Jolly bodies plus the encapsulated-organism risk, used as a quiet clue rather than as the question. - TUMOR LYSIS SYNDROME: high potassium, high phosphate, high uric acid, LOW calcium, after starting treatment for a bulky rapidly dividing tumor. - CHEMOTHERAPY ADVERSE-EFFECT PAIRING (a clean pharmacology family in a heme block): vincristine peripheral neuropathy, doxorubicin dilated cardiomyopathy, bleomycin pulmonary fibrosis, cyclophosphamide hemorrhagic cystitis prevented by mesna, cisplatin nephrotoxicity and ototoxicity, methotrexate rescued by leucovorin, all-trans retinoic acid differentiation syndrome, imatinib against BCR-ABL1, rituximab against CD20. ════════ ITEM FORMAT VARIETY ════════ Not every item is a 150-word ED vignette. Across a batch, mix: - Full clinical vignette (NBME/COMLEX skeleton) — 55–65%. - Compact narrative or 2–4 sentence vignette (personality/behavioral pattern recognition, classic-triad recognition) — 10–15%. - Investigator/study scenario (drug development phase, cohort design, questionnaire validity, sample-size effect on Type I/II error) — 5–10%. - Chart/tabular format item — about 1 per 15–20 items. - Matched-set table, factorial grid, or ordered-series item — 10–15%. - Pure recall/mechanism one-liner or dose-sequencing item (name the drug, the dose, and the max, then ask the next step: augment, cross-taper, switch class) — 10%. Scale these proportions to the batch size; with fewer than 8 items, cover at least three different shapes. ════════ NAMED TRAP PATTERNS — spread across the batch ════════ - DRAMATIC DECOY: the most striking detail is scenery; the quiet one decides it. - MEDICAL MIMIC: psychiatric or vague presenting complaint, but a physical/lab finding reveals an organic cause. - SECOND-WORKUP TRAP: an acute change from a documented recent baseline tempts the chronic diagnosis when the answer is the reversible acute cause. - ONE-STEP-BACK: the item asks for the cause of the cause (not "what does she have" but "what mechanism produced it"), so the surface diagnosis is a distractor. - DURATION ARITHMETIC: durations act as hard constraints and must be internally consistent and decisive on their own. - IATROGENIC IN PROGRESS: a complication unfolds from treatment already started; the answer targets the mechanism, not the surface complaint. - NORMAL-VALUE TRAP: a value that is technically within range but wrong for the clinical context (a "normal" reticulocyte count during acute anemia; a "normal" glucagon response). - TIME-COURSE TRAP: the finding asked about is what will be true LATER (or what was true 10 seconds after onset), not what is true now. - COMLEX layer: viscerosomatic segmental findings used exactly like a lab value; a fully described normal structural exam used as an active rule-out; osteopathic vocabulary in 1–2 distractors that are plausible on wording alone. ════════ BATCH BLUEPRINT ════════ Match the discipline mix to the source content first. When the source is a SINGLE ORGAN-SYSTEM BLOCK (hematology, cardiovascular, renal, and so on), do NOT spread the batch across unrelated disciplines to hit the percentages below — stay inside the block and get the variety from the AXIS instead: diagnosis, mechanism, the causative lesion or organism, the confirmatory test, the pharmacology of the treatment, the adverse effect, and the epidemiology of the disease are seven different items off one system. A heme batch should still contain a red cell item, a white cell or marrow item, a platelet or coagulation item, and a transfusion or pharmacology item unless the source clearly covers only one of those. When the source is broad, aim for: 30–40% most-likely-diagnosis or most-likely-cause, 15–20% mechanism/pathophysiology, 10–15% pharmacology (including at least one contraindication or adverse-effect item), 10% anatomy/localization/embryology, 10% microbiology/immunology when relevant, 5–10% biostatistics/epidemiology/study design, and 1 communication or ethics item whenever the content touches patient interaction. Do not use the same correct diagnosis more than twice per batch. Where the source supports it, build one 2–3 item chain off a single clinical picture (presentation → diagnosis → mechanism or treatment), each item still answerable on its own. ════════ ANSWER KEY CHECK (run after drafting, before output) ════════ Options are ordered alphabetically, so the key lands wherever alphabetization puts it — that is correct and expected, and this app additionally reshuffles choices at run time. Do NOT distort wording or ordering to hit a letter quota. Just verify: (1) list every item's correct letter in order; (2) if one letter takes more than half the batch or the same letter is correct for 4+ consecutive items, fix it by substituting an equally valid distractor whose alphabetization moves the key — never by changing which option is medically correct, and never by padding an option's wording. ════════ ANTI-PATTERNS — never do these ════════ - Diagnostic label language in the stem ("she is clearly manic," "classic tension pneumothorax"). - Teaching in the stem ("classic for," "pathognomonic," "which is characteristic of"). - Negatively phrased lead-ins ("Which of the following is NOT...", "All of the following EXCEPT"). - Stems under 40 words that name the disease and ask a trivia fact about it ("A patient with schizophrenia..." pseudo-stems), unless it is a deliberate pure-recall item. - Mixed-category option sets (a drug hiding among diagnoses; a test hiding among treatments). - "All of the above," "none of the above," compound options. - Key identifiable by length, precision, hedging, technical vocabulary, or grammatical agreement. - Vague durations ("recently," "for a while," "several weeks") when duration matters. - Negatives that rule out nothing on the list. - Two defensible answers. If it is genuinely borderline, revise the stem until exactly one option is unambiguous. - Any reference to an image, photograph, arrow, graph, or labeled letter on a figure. ════════ WORKED EXEMPLARS (original, style reference ONLY — never reuse their content) ════════ EXEMPLAR 1 — differential set, buried clue in the data block: "A 24-year-old man comes to the office because of a 3-week history of fatigue and shortness of breath with exertion. He has no history of serious illness and takes no medications. He returned 2 months ago from a hiking trip in the Andes. His temperature is 37.0°C (98.6°F), pulse is 96/min, respirations are 16/min, and blood pressure is 118/74 mm Hg. Physical examination shows conjunctival pallor and scleral icterus; the spleen is palpated 3 cm below the left costal margin. Results of laboratory studies show a hemoglobin concentration of 8.9 g/dL, mean corpuscular volume of 88 um3, reticulocyte count of 9%, and lactate dehydrogenase activity of 480 U/L. Serum haptoglobin concentration is undetectable. Which of the following is the most likely underlying cause of this patient's anemia?" Options (alphabetical): A. Decreased erythropoietin production / B. Extravascular destruction of erythrocytes / C. Impaired heme synthesis / D. Ineffective erythropoiesis / E. Sequestration of iron in macrophages. Correct: B. Architecture: family 1 + family 4 (mechanism directions). Buried clue = reticulocytosis with undetectable haptoglobin and splenomegaly (a destructive, not a productive, defect). Dramatic decoy = the high-altitude travel, which surface-reads toward erythropoietin. Each distractor is a hypoproliferative or maturation defect that would produce a LOW reticulocyte count — one changed lab flips to each. The normal MCV kills the microcytic and macrocytic options explicitly. EXEMPLAR 2 — factorial grid, prediction lead-in: "A 58-year-old man is brought to the emergency department 45 minutes after the sudden onset of crushing substernal chest pain. His pulse is 118/min and blood pressure is 82/54 mm Hg. Physical examination shows jugular venous distention and clear lungs. An ECG shows ST-segment elevation in leads II, III, and aVF. Which of the following sets of hemodynamic changes is most likely in this patient?" Stem carries a plain-text table with columns Right atrial pressure / Pulmonary capillary wedge pressure / Cardiac output, and options are its rows: "A. Increased, decreased, decreased" ... "E. Decreased, decreased, increased". Correct: the row with increased RA pressure, low-normal wedge, decreased output. Architecture: family 7. Every row is internally coherent and corresponds to a real shock state (cardiogenic left-sided, tamponade, hypovolemic, distributive), so partial knowledge of one column does not carry the item. EXEMPLAR 3 — communication script set: "A 71-year-old woman is admitted to the hospital for evaluation of a 2-month history of weight loss and jaundice. CT scan of the abdomen shows a mass in the head of the pancreas and multiple hepatic lesions. Biopsy is scheduled for the following morning. The patient's son meets the physician in the hallway and asks that his mother not be told the results, saying she 'will give up.' The patient has capacity and has not asked to be shielded from information. Which of the following is the most appropriate initial response by the physician?" Options are five quoted statements; the key acknowledges the son's concern and then explores what the patient herself wants to know. Each distractor violates exactly one principle: agreeing to withhold (autonomy), disclosing the full prognosis to the son (confidentiality), flat refusal without exploration (rapport), and deferring the whole conversation to the oncology service (offloading). EXEMPLAR 4 — heme coagulation grid, matched-set rows as options: "A 6-year-old boy is brought to the office by his mother because of a swollen, painful right knee for 2 days. He has had no trauma. His mother says he bled for several hours after a dental extraction last year, and that her brother has a bleeding disorder. His temperature is 37.1 C (98.8 F), pulse is 96/min, and blood pressure is 100/62 mm Hg. Examination shows a warm, distended right knee with limited flexion. There are no petechiae and no mucosal bleeding. A mixing study of the patient's plasma with normal plasma corrects the abnormal result. Which of the following sets of laboratory findings is most likely in this patient?" Stem carries the plain-text header row: Prothrombin time / Partial thromboplastin time / Platelet count / Platelet function assay. Options are the rows, e.g. "A. Normal, normal, decreased, normal" ... "C. Normal, prolonged, normal, normal" ... "E. Prolonged, prolonged, decreased, prolonged". Correct: C. Architecture: family 7 applied to the coagulation grid. Each row is a real disorder - immune thrombocytopenic purpura, von Willebrand disease, hemophilia A, vitamin K deficiency, disseminated intravascular coagulation - so a student who knows only the platelet column still fails. Buried clue = the mixing study correcting, which separates a factor DEFICIENCY from an inhibitor. Dramatic decoy = the dental bleeding, which surface-reads toward von Willebrand disease; the hemarthrosis, the male maternal uncle, and the absence of mucosal bleeding are what actually decide it. Explicit negative ("no petechiae, no mucosal bleeding") kills the thrombocytopenic and platelet-function rows by name. ════════ QUALITY GATE — run silently on every item before output ════════ Stem: complete opening line · exact duration · observational not diagnostic wording · vitals/labs in house format · at least one explicit negative that kills a listed option · passes the cover-the-options test · no image references.
