# How this was built

A dev log for future-me (or a future Claude session) picking this back up.

## What this is

An interactive, offline HTML study version of the "Lumbar Spine, Pelvis, and Sacrum, Screening and Diagnosis OMM Exam 26-27" rubric (the faculty grading rubric for the OMM skills-test practical). Every screening/diagnosis test row is interactive: hover (desktop) or tap (touch) shows purpose / step-by-step technique / diagnosis-naming logic / reference photos (where a good one exists) for that row.

It's a single self-contained HTML file (`Lumbar Spine, Pelvis, and Sacrum, Screening and Diagnosis OMM Exam.html`) plus an `assets/` folder of images. No build step, no server, no dependencies — just open the HTML file in a browser (or serve the folder for the most reliable local preview — see "Verifying" below).

This is the **second** of five related OMM rubrics being built from the same source PDF (the first, Axial Spine and Ribs, is already done; Upper Extremity, Lower Extremity, and a treatment-technique rubric are still future builds). Unlike the first build, this one was **not** built from scratch — it was built by copying the Axial Spine and Ribs rubric's *final, post-polish* architecture line-for-line (same CSS, same JS interaction logic, same per-row 4-column grading, memory hooks, text-size control, row-number badges, and expand-to-reader-modal button that rubric ended up with after two rounds of user feedback). See that rubric's own `BUILD_NOTES.md` — especially its "Round 2: user-requested refinements" section — for the full history of how that architecture was arrived at and why. Nothing architectural was re-invented here; this file only documents what's specific to the lumbar/pelvis/sacrum content.

## Row structure

15 rows total, following the source PDF exactly:

1. Communication (plain row, no popover)
2. Consent (plain row, no popover)
3. Washes Hands (plain row; only 2 real grading options, middle two are `N/A-DO NOT SELECT`)
4–13. Ten hoverable rows (Lumbar Spine Screening/Diagnosis, Innominate Screening/Supine/Prone/Accuracy, Sacrum Screening/Prone/Spring&Sphinx/Accuracy) — see below
14. CAP summary: "Did the Student have to CAP this Rubric?" (plain row, own 4-option wording)
15. CAP summary: "Was the CAP completed successfully?" (plain row, own 4-option wording)

**A wrinkle not present in the Axial Spine/Ribs rubric:** four of the ten hoverable rows (9 "Accuracy of Innominate Diagnosis", 13 "Accuracy of Sacrum Diagnosis") use `100% Correct` as the first-column label instead of the usual `100% Correct and Fluid` — the source PDF drops "and Fluid" specifically for these two short "Accuracy of X" summary-style rows, while rows 4–8 and 10–12 keep the standard 4-option wording used throughout the first rubric. This was called out explicitly in the task brief and double-checked against the row text given, since it would have been an easy detail to silently flatten to the more common pattern. Both rows' `<label title="...">` and abbreviated `<span class="grade-text">` reflect this (title="100% Correct", not "100% Correct and Fluid").

No student-name/date header fields were added, matching the source PDF and the first rubric's precedent.

## How the content got in there

1. **Rubric skeleton (all 15 rows, exact wording, exact per-row column labels)**: transcribed directly from the task brief, which itself was checked against the same OMM Week 1 course-notes source file used for the first rubric.
2. **Rows 4–13 popover content (purpose / how-to-perform / diagnosis-naming logic)**: sourced from the Week 1 OMM notes' "Pelvis/sacrum step | What it tells you | Practical pitfall" table, the "Innominate Quick Table" and "Sacral Torsion Quick Table" (both under LO4, "Regional Naming Atlas"), and the worked case-based practice-question examples under "Active Recall." The lumbar-spine rows (4–5) reused the same Fryette Type I/II framework and thoracic/lumbar screening bullets already used for the axial-spine rubric's thoracic rows, adapted to the lumbar-specific pitfall called out in the source text ("too much motion leaks into the pelvis/SI").
3. **Rows 4 and 11 reference images**: one reused (recropped/renamed, not referenced from the other rubric's folder) from the Week 2 lecture deck, one new one from the Week 5 lecture deck. See row-by-row list below.

Every image caption ends with a short `(Source: ...)` note for traceability, matching the first rubric's convention.

## Row-by-row sourcing (rows 4–13, the only rows with popovers)

- **Row 4 (Lumbar Spine Screening)** — `assets/lumbar_screen_seated.jpg`, converted from `omm2_img007.webp` ("Thoracic/Lumbar Screen" slide, Week 2 deck). Per the task instructions, the file was **copied and converted independently into this project's own `assets/` folder** under a new filename rather than referencing the other rubric's folder, so the two rubrics stay fully self-contained.

No dedicated lumbar-diagnosis photo was found in any of the checked source decks (omm2, omm3, omm5); the technique is identical in principle to the thoracic 3-position diagnosis already photographed in the first rubric (`managing_seated_torso.jpg` there), but that specific photo lives in the other rubric's own project folder and wasn't a strong enough match to justify copying it over just to fill space — the row's text (adapted directly from the Week 1 notes' Type I/II table and the L4 FSRr worked example) carries the teaching content on its own.
- **Row 6 (Innominate Screening — Standing Flexion Test)** — text only. Checked `omm_stripped/omm2`, `omm3`, `omm5` for a standing-flexion-test photo/diagram; none exists in the provided source decks. A web search for open-licensed (Wikimedia Commons) images of the standing flexion test returned no results — this is a very standard OMT maneuver but apparently not one with a freely-reusable photo readily indexed. Text-only, sourced from the Week 1 notes' pelvis/sacrum pitfall table.
- **Row 7 (Supine exam — ASIS/pubic tubercles/compression)** — text only. No supine-pelvis-exam photo was found in any checked deck. Sourced from the Week 1 notes' pitfall table and Innominate Quick Table.
- **Row 8 (Prone exam — PSIS)** — text only. `omm3_stripped.html`'s "Sacrum Still" image and `omm2_stripped.html`'s "Lumbar Still Diagnosis" image were both viewed directly and confirmed to be treatment-technique photos (Still technique / lower-extremity positioning for treatment), not screening/diagnosis photos — correctly excluded per the task's own screening/diagnosis-only scope, same reasoning the first rubric's BUILD_NOTES documents for its excluded "Rib Still Arm Arc" and FPR/Still setup photos.
- **Row 9 (Accuracy of Innominate Diagnosis)** — text only, as expected for a short "accuracy of naming" row (the first rubric's equivalent-style rows also didn't carry photos). Content is the Innominate Quick Table plus the standing-flexion-positive-right worked example from "Active Recall."
- **Row 10 (Sacrum Screening — Seated Flexion Test)** — text only. Same search result as row 6: no seated-flexion-test photo in the provided decks, and no open-licensed match found via web search. Sourced from the Week 1 notes' pitfall table.
- **Row 11 (Prone exam — sacral base/ILA)** — `assets/posterior_pelvic_ligament_anatomy.jpg`, converted from `omm5_img033.webp` ("Sacroiliac Joint Dysfunction" slide, Week 5 deck). **Judgment call, flagged explicitly:** this is a labeled anatomical diagram ("Pelvis and Ligaments, Rear View, Female" — posterior sacroiliac, sacrotuberous, interosseous sacroiliac, and dorsal sacrococcygeal ligaments) embedded in a slide about SI joint dysfunction epidemiology and orthopedic special tests (FABER, Gaenslen's, etc.) that aren't part of this OMM structural-exam rubric at all. It is **not** a technique photo — no one is shown palpating anything — so it was captioned honestly as "an anatomy reference, not a technique photo" rather than presented as if it demonstrated the prone sacral exam. It was still included (rather than left out entirely) because it's a genuinely useful, correctly-labeled landmark reference for orienting to the sacral-base/ILA region described in the row text, and the task brief explicitly OK'd "don't force a bad match" while also encouraging real images where reasonably available. Worth a second look if a cleaner prone-sacral-exam technique photo turns up in a future source file.
- **Row 12 (Spring and Sphinx Tests)** — text only. `omm3_stripped.html`'s "Sacrum Still" image (a Still-technique treatment photo, patient supine) and "Sacral ligaments mimic radiculitis" image (a dermatome/referred-pain diagram, not a technique photo) were both viewed and correctly excluded — neither shows the spring or sphinx test. Sourced from the Week 1 notes' pitfall table and Sacral Torsion Quick Table.
- **Row 13 (Accuracy of Sacrum Diagnosis)** — text only, same reasoning as row 9. Content is the full Sacral Torsion Quick Table (all four torsion patterns spelled out as steps) plus the left-sulcus/right-ILA worked example from "Active Recall."

**Net result: 2 of 10 hoverable rows have a photo (rows 4 and 11); the other 8 are text-only.** This rubric is noticeably more text-heavy than the Axial Spine/Ribs rubric (which ended up ~75% illustrated after its Round 2 re-sourcing pass pulled real textbook photos from OPP Vol. 1). That's a genuine reflection of the source material available, not a shortcut: the Week 1 course notes cover pelvis/sacrum in real depth (two dedicated quick-tables plus worked examples), but the Week 2/3/5 lecture decks checked for this build simply don't contain photographed technique demonstrations of the standing flexion test, seated flexion test, ASIS/PSIS palpation, or spring/sphinx tests the way they do for the cervical/thoracic/rib maneuvers — those decks' pelvis/sacrum content is almost entirely either treatment-technique photos (Still, BLT — out of scope for a screening/diagnosis rubric) or non-technique diagrams (referred-pain patterns, SI-joint anatomy). If the OPP textbook excerpts that later filled in rows 5 and 9 of the first rubric ever get a pelvis/sacrum chapter equivalent, revisit rows 5–10 and 12 here the same way.

Two Week 4 images ("SI Joint BLT," appearing twice) were also checked and excluded — they're Balanced Ligamentous Tension treatment setups, not screening/diagnosis photos, same category as the excluded Still-technique images above.

## Architecture elements replicated from the reference rubric (confirmed by direct comparison, not assumption)

- Single self-contained HTML + `assets/` folder, no `index.html` naming.
- `DATA` object keyed by row number 4–13 (the ten hoverable rows only), each with `name`, `purpose`, `hook`, `steps[]`, `normal`, and `images[]` (empty array where no image was found, matching the reference's pattern of including the key with no `images` property — here `images: []` is used explicitly for the text-only rows for clarity, which `buildContent()` already handles safely since `d.images && d.images.length` gates the image block).
- Per-row 4-column grading: native `<input type="radio" name="r{n}">` per row (single-select for free), abbreviated `<span class="grade-text">` labels, full original wording preserved as `title=""` on the `<label>`, `.is-na` modifier on N/A cells.
- `table-layout:fixed` with `col.col-grade{width:5.5%}` / `col.col-test{width:78%}` — identical to the reference's final (post-polish) column widths.
- Row numbers as `.row-num-badge` spans, `float:right`, injected as the first child of each description `<td>` — no dedicated row-number column exists anywhere in this file (verified: `td.row-num`/`td.col-num` selectors return 0 elements).
- Dual interaction mode: sticky `#sidePanel` at ≥1300px via `showInPanel()`, floating `#popover`/`#overlay` below that via `openPopover()`/`positionPopover()`/`closePopover()`.
- Click-to-enlarge `#lightbox` for every image.
- Expand button (`#sideExpandBtn` / `#popExpandBtn`) opening `#readerModal`/`#readerContent` at `zoom:1.35`, tracked via a shared `currentKey` variable set in both `showInPanel()` and `openPopover()`; `#readerModal` at `z-index:1800`, between the popover (1000) and the lightbox (2000). All shared `#popover X, #sidePanelContent X{...}` CSS rules also include `#readerContent X` — written by hand for each rule (not via a broad regex — see the bug warning below), and confirmed working live: an image clicked inside the expanded reader opens the lightbox on top of it.
- Text-size control: floating A−/A+ pill, `--font-scale` CSS variable, persisted to `localStorage` under `omm-lumbar-pelvis-sacrum-font-scale` — **a new, file-unique key**, deliberately different from the first rubric's `omm-axial-ribs-font-scale` so the two rubrics' saved text-size preferences don't collide if ever opened in the same browser.
- Both historical bugs avoided: `closePopover()` resets `popover.style.display = ''` (not just the `.open` class); the base `#sidePanel{ display:none; }` rule appears before its `@media (min-width:1300px)` override in source order.

## On the "don't bulk-regex across the whole file" warning

The task brief flagged a real bug from the first rubric's build: a Python regex meant to extend `#sidePanelContent SELECTOR{...}` rules to also match `#readerContent SELECTOR{...}` was accidentally run across the entire file including the `<script>` block, and its non-greedy-but-still-`{`-seeking pattern scanned forward across unrelated JavaScript lines and corrupted them — producing a page that looked fine in a screenshot but had zero working interactivity.

This build was written by hand from the reference file's finished (post-fix) CSS and JS as a template — there was no need to run any bulk find/replace across CSS+JS together, so that specific failure mode doesn't apply here. The verification discipline was still followed in full anyway (see below), since a hand-written 900+ line file has its own ways to introduce a typo.

## Round 2: re-sourcing images from user-supplied OPP textbook PDFs

The gap documented above — 8 of 10 hoverable rows text-only — got closed almost entirely once the user supplied two new source PDFs: `Sacrum.pdf` (OPP Vol.1, UNECOM 2025, Chapter 10 "Sacrum," book pages 257–271) and `lumbar.pdf` (same volume, "Lumbar Spine" chapter, book pages 232–238). These are the actual textbook chapters with real technique photographs for exactly the tests this rubric grades — the same category of source that filled in rows 5 and 9 of the Axial Spine/Ribs rubric during its own Round 2.

**Extraction method:** `pdftoppm -r 300 -png` rendered each page to a full-resolution PNG (2550×3300 at 300dpi), matching the method already established (and already known to beat `pdfimages`, which fragments these particular scans). Rather than manually eyeballing crop coordinates per photo, a small PIL helper (`crop.py`, in the scratchpad) scans each page region row-by-row for near-white gaps ≥15–25px and auto-splits the region into separate content bands — this handled multiple stacked photos per page (e.g. two Seated Flexion Test photos, two Spring Test photos) without manual coordinate-guessing, and each resulting crop was visually reviewed via the Read tool before being kept. Two crops (the sacral diagnosis table and the quick-reference diagram) were initially cut off at the bottom on the first pass and re-cropped with a taller bound — a reminder to always review a crop against the full source page rather than trusting the first attempt.

**New images added (7 new files, 1 new page revisited for a photo already documented above):**

- **Row 4 (Lumbar Spine Screening)** — added `hip_drop_test.jpg` and `lumbar_rotation_pelvic_roll.jpg` (OPP Vol.1 Lumbar Spine chapter, pp.234/236) alongside the existing `lumbar_screen_seated.jpg`. **Judgment call:** these two are general *regional* screening tests (Hip Drop Test, Lumbar Rotation/Pelvic Roll), not the specific *segmental* compression screen the row's `steps` describe — captions say so explicitly ("distinct from the segmental compression screen above, but commonly used alongside it") rather than implying they're the same technique. Included anyway because the source rubric's row title is the broader "LUMBAR SPINE SCREENING," not "segmental screening" specifically, and a student studying this row benefits from seeing the full family of screening tests the textbook groups together.
- **Row 5 (Lumbar Spine Segmental Diagnosis)** — added `transverse_process_palpation.jpg` and `lumbar_segmental_extended_position.jpg` (OPP Vol.1 Lumbar Spine chapter, pp.237–238). These are direct, precise matches: "Transverse Processes Palpation" shows exactly the thumb-lateral-to-spinous-process contact the row's static-screen step describes, and "Testing in the Extended Position" shows exactly the seated-arch-back 3-position technique. This was the single biggest content upgrade in this round — row 5 went from zero images to two textbook-accurate ones.
- **Row 10 (Sacrum Screening — Seated Flexion Test)** — added `seated_flexion_test.jpg` (OPP Vol.1 Sacrum chapter, p.266). Exact match: same feet-flat-on-floor, thumbs-under-PSIS setup the row describes, shown as a two-photo sequence (thumb contact, then forward bend).
- **Row 11 (Prone Sacral Exam)** — added `sacral_sulci_palpation.jpg` and `inferior_lateral_angle_palpation.jpg` (OPP Vol.1 Sacrum chapter, p.267), placed ahead of the existing `posterior_pelvic_ligament_anatomy.jpg` anatomy reference (kept, still useful, now clearly secondary). These are exact matches for the row's two named landmarks — sulcus palpation (thumbs rolling superior/medial from PSIS) and ILA palpation (thumbs walking inferior to the sacral apex), each shown once on a bone model and once on a real patient.
