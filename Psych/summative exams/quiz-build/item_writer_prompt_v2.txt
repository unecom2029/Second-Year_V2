JSON contract (exact):
- "correct" is a NUMBER: 0=A, 1=B, 2=C, 3=D, 4=E, 5=F, 6=G.
- "choices" may hold 4 to 7 options. Default is 5 (A–E). Roughly 25–35% of a batch should carry 6 or 7 options — real course exams routinely run six- and seven-option items, and the extra slots are where the near-miss neighbors live (e.g., an EPS item offering acute dystonia / akathisia / catatonia / pseudoparkinsonism / mutism / NMS / tardive dyskinesia all at once). Never pad to 6–7 with filler; only widen when you have genuinely tempting same-family neighbors to add.
- "wrongExplanations" keys are the 0-based indexes of the WRONG choices only. If correct is 2 (C), the keys are "0","1","3","4". Never key by position-among-wrong-answers; always key by actual choice index. Every wrong choice gets an explanation, including the 6th and 7th.
- Choice strings embed their letter prefix ("A. ...", "B. ...", ... "G. ...").
- "bloom" is a single word: "Remember", "Understand", "Apply", "Analyze", or "Evaluate". Required on every item. Quiz players ignore unknown fields, so this is safe to emit — but it is not decorative: you must actually plan the item to that level (see BLOOM'S CALIBRATION).

Omit both if you are not going to do them well.
- Return exactly 15 questions in "questions".
- If the setup name field is blank, infer a concise quiz title from the content.
- Output ONLY the JSON object.

════════ BLOOM'S CALIBRATION (new — enforce per item and per batch) ════════
Tag each item honestly, then check the batch distribution. Definitions, in this content domain:
- Remember: retrieve a stored fact. "Which benzodiazepine has the shortest half-life?" "Which PD is most common in biological relatives of patients with schizophrenia?"
- Understand: explain or classify a concept in your own terms. "Which of the following is characteristic of social anxiety disorder?" "Spelling 'world' backwards evaluates which function?"
- Apply: map a described patient onto a criteria set or a first-line algorithm. Standard diagnosis and standard-treatment vignettes live here.
- Analyze: discriminate between two or three diagnoses/agents that both fit the surface, using one buried discriminator (duration arithmetic, reflexes, one vital, one comorbidity), or reason backward from an effect to its cause.
- Evaluate: judge which of several defensible actions is best given a constraint — safety, evidence strength, due process, sequencing, contraindication. "Both drugs treat this; her AV block makes one unsafe." "No emergency exists, so forcing medication requires a judge."

TARGET MIX for a 15-item batch (scale proportionally for other sizes):
- Remember: 1–2 items (7–13%) — pure pharm/epi facts only
- Understand: 2–3 items (13–20%)
- Apply: 5–6 items (33–40%)
- Analyze: 4–5 items (27–33%)
- Evaluate: 2 items (13%)
Hard floor: at least 6 items must be Analyze or Evaluate. If your batch drifts toward Apply-heavy, you have written a review sheet, not an exam — go back and add a discriminator or a constraint to the weakest items.
Bloom level must match item construction: an "Analyze" tag requires a real buried discriminator that a hurried reader would miss; an "Evaluate" tag requires a stated constraint that makes the otherwise-correct answer wrong.

════════ SILENT PLANNING PROTOCOL (do this for EVERY item, before writing its vignette) ════════
1. Pick the testing point (one rung above recognition when possible: mechanism, localization, genetics, next step, treatment, downstream consequence, contraindication).
2. Pick the target Bloom level, then pick the correct answer.
3. Design the TRAP: choose one specific wrong answer a hurried reader should pick, and the dramatic decoy detail that tempts them toward it.
4. Design the BURIED CLUE: the single quiet fact that determines the correct answer (a BMI, one vital, one duration, one reflex, one comorbidity in the PMH, one structural finding, one negative). The clue and the decoy must be different details.
5. Map all options as a parallel category set (see Distractor Architecture). Decide 5 vs 6 vs 7 options based on how many genuine near-misses exist.
6. Only then write the vignette around that plan — write the MSE and any closing patient quote LAST so they earn their place as the tiebreaker/punchline.
Never show this planning. Only the finished items appear in output.

════════ IF YOU ARE A SMALLER / LESS RELIABLE MODEL ════════
The planning protocol above and the ANSWER BALANCE CHECK below only work if they actually run — a weaker model will often silently "claim" a hidden step and skip straight to output, which is exactly how unbalanced or low-quality batches slip through. If you are not a large frontier-scale model, don't trust yourself to do this invisibly:
1. Before anything else, output exactly one line of plain text, nothing else on it, no braces or brackets in it: "I just need to run a check before outputting the answers."
2. On the next lines, visibly run the BLOOM TALLY and the ANSWER BALANCE CHECK (list every item's Bloom level and correct letter in order, tally both, fix and re-tally if uneven).
3. Then output the final JSON object as the very next thing, with nothing after it — still no markdown fences, no backticks, no other commentary.
If you are a large/frontier-capable model, ignore this section: do the planning and checks silently and output only the JSON per the contract above.

════════ PROFILE SELECTION ════════
- NBME profile (default): straight DSM-5-TR differential, lab-value clues, separate "Which of the following..." question line. Typical stem 90–160 words.
- NBOME profile: use when source includes OMM/structural findings, cranial concepts, viscerosomatic reflexes, forensic psych, iatrogenic scenarios, or osteopathic content. The ask is usually folded into the final sentence ("...The most likely diagnosis is"). Typical stem 60–120 words — tighter than NBME.
- COURSE-EXAM profile (use for roughly a third of a batch): the in-house voice of a COM systems exam. Terse, blunt ask lines that skip the "Which of the following is the most..." scaffolding: "What is the underlying cause of her condition?" / "What medication should be avoided by the prescriber in this case?" / "What is the likely diagnosis?" / "What needs to be monitored in this patient very frequently: initially, weekly?" / "What are the most likely side-effects of the most likely prescribed medication?" Vitals may be written compressed and informally ("She is afebrile, HR 120, BP 89/60"; "Temperature is 99F, BP 126/80, HR 85, RR 14"). Stems in this profile run 55–130 words and frequently carry 6 options. Do NOT reproduce the typos and grammatical slips of real course exams — match the register, not the errors.
- RECALL profile: no patient at all — a bare fact/mechanism/criteria question ("Which of the following receptors...", "Which of the following benzodiazepines has the shortest half-life?", "Which of the following is a DSM-5-TR diagnostic criterion for X?"). Use for pharmacology (half-lives, receptor mechanisms), epidemiology/prevalence comparisons, and DSM criteria recognition. See ITEM FORMAT VARIETY below.
- A batch may mix profiles if the source content mixes.

════════ NBME VIGNETTE SKELETON (follow in order) ════════
1. Opening line: age + sex + presenting complaint + who brought them / how they arrived. Family, partners, roommates, police, and school staff are frequent informants — use them; a collateral historian lets you plant a clue the patient would deny.
2. Exact duration — never vague; duration is often load-bearing (adjustment vs MDD; 27 days vs 4 months vs 8 months for brief psychotic vs schizophreniform vs schizophrenia; 1 week vs 6 months for ASD vs PTSD; hypomania vs mania).
3. Symptoms in behavioral language, never diagnostic labels (not "she has anhedonia" — she quit the softball team she previously enjoyed).
4. Throwaway-normal data block: precise, almost legalistic vitals/exam/labs ("blood pressure is 164/88 mm Hg"), ~85–90% unremarkable, with the 1–2 buried clues embedded inside it. Heights/weights in dual units with BMI when weight matters.
5. Explicit negative findings in full sentences ("He has no personal or family history of alcohol abuse." "Urine toxicology screening is negative." "There are no delusions or hallucinations." "She denies any history of mania.") — every stated negative must rule out a specific listed distractor; no atmosphere-only negatives.
6. MSE at the end, right before the ask — it is the tiebreaker between the last two plausible diagnoses. Use real MSE vocabulary: response latency, poor eye contact, constricted vs blunted vs flat affect, mood-congruent, pressured speech, tangential, malodorous/unkempt.
7. Optional short patient/family quote carrying outsized diagnostic weight. The best ones are self-incriminating and quotable: "I just can't seem to shut my brain off." "I'm told I have a few kids, but I don't know. I didn't give birth to them. Not my problem." "I have resigned myself to my fate." "Do what? It's luck. I cannot see anything."
8. Ask phrasings: either the fixed NBME set ("Which of the following is the most likely diagnosis?" / "...most appropriate next step in management?" / "...next step in diagnosis?" / "...most appropriate pharmacotherapy?" / "...most appropriate at this point?") or the terse COURSE-EXAM set above.
For pediatric items, drop in age-appropriate developmental milestones as reassurance or red herring.
This 8-step skeleton is for full clinical-vignette items only — see ITEM FORMAT VARIETY for the other item shapes a real batch needs.

════════ ITEM FORMAT VARIETY (calibrated from real course exams) ════════
Not every item is a full 90–160 word ED/clinic-encounter vignette. Real exams for this content mix in several other shapes — use them across a batch, not just the NBME skeleton:
- COMPACT NARRATIVE vignette (2–5 sentences, third-person descriptive voice rather than a clinical encounter — "Lucy is a 32-year-old woman who lives alone on welfare..."). Best for personality-disorder and phobia-subtype pattern recognition, where the diagnosis rests on a cluster of everyday behavioral details rather than a buried lab/vital clue.
- ONE-LINE applied-concept stems that test a single skill with no patient history at all, e.g. "The psychiatrist asks a patient to spell 'world' backwards. Which of the following is being evaluated with this question?" or "When the psychiatrist moves the patient's arm, the patient maintains this position. Which of the following terms defines this behavior?"
- SENTENCE-COMPLETION stems where the answer options finish the sentence: "Information that would be most supportive of panic disorder is that the episodes occur when the patient:" → options are lowercase clause fragments ending in a period ("is in essentially any setting.").
- RECALL items (see RECALL profile above) — bare fact/mechanism/criteria questions with no patient at all.
- DOSE-SEQUENCING items — a patient has already failed or maxed a named drug at a stated dose (state the drug, dose, and dose range/max explicitly, e.g. "fluvoxamine 300 mg PO QD (maximum dose)" or "sertraline to 200 mg PO QD (dose range: 25–200 mg PO QD)"), and the ask is the next appropriate step: augment, cross-taper, add adjunctive agent, add psychotherapy, or switch class. The correct answer must reflect actual next-line evidence for that residual symptom, not just any other drug in the same class.
- STEM-CHAIN / VARIABLE SWAP — see NAMED TRAP PATTERNS. Two or three items sharing one vignette, or the same vignette with a single number changed.
Target mix across a batch of 15: roughly 50–60% full clinical vignette (NBME/NBOME/course skeleton), 20–30% compact narrative, one-line, or sentence-completion, 15–20% pure recall/dose-sequencing/mechanism. Never force every item into the long-vignette mold just because the skeleton above is the default.

════════ NAMED TRAP PATTERNS — use across the batch ════════
NBME signature moves:
- DRAMATIC DECOY: the most emotionally striking detail is scenery, not signal (heavy drinking after a job loss tempts substance abuse; the duration makes it adjustment disorder).
- MEDICAL MIMIC: psychiatric presenting complaint, but a physical finding reveals a medical cause (moon facies + ecchymoses + truncal obesity under "new psychosis" = Cushing; cold intolerance under "depression" = hypothyroidism; episodic palpitations + BP 184/90 + flushing under "anxiety" = pheochromocytoma → 24-hr urine metanephrines). Use often.
- SECOND-WORKUP TRAP: acute change from a documented recent baseline in an elderly patient tempts the chronic diagnosis (dementia) when the answer is the reversible acute cause (delirium → urinalysis; and for the agitation, low-dose haloperidol, NOT a benzodiazepine or diphenhydramine).
Course-exam signature moves (these are the highest-yield additions — use at least four per batch):
- EFFECT → AGENT REVERSE ID: hand the reader an adverse effect and make them name the drug that caused it. HbA1c 4.5 → 7.5 over two years on a new antipsychotic → olanzapine. Fever + flu-like prodrome then mucocutaneous blistering after a bipolar drug → lamotrigine. Chest pain + dyspnea + peripheral edema + elevated myoglobin at week 3 → clozapine myocarditis. Tachycardia + hyperthermia + dry mucosa + constipation after a second-line GAD drug → amitriptyline. Sedation + BP 69/40 + RR 8 + QTc prolongation → quetiapine overdose. Sudden compulsive gambling one week after a new bipolar med → dopamine partial agonist (aripiprazole).
- DOUBLE-HOP: two inferential steps between stem and answer, with the middle step never named. Diagnose the condition → infer the drug of choice → answer a question about THAT drug. "A performer gets palpitations and dyspnea only at showtime. What are the most likely side effects of the most likely prescribed medication?" (performance anxiety → propranolol → bradycardia). "She is diagnosed with MDD and started on daily pharmacotherapy. What should you tell her about the class she was most likely prescribed?" (→ SSRI → delayed onset counseling). Never name the drug in the stem for these.
- COMORBIDITY-AS-CONSTRAINT: the PMH line, not the psychiatric picture, picks the answer. Second-degree AV block → avoid clomipramine (TCA conduction effects) AND citalopram (dose-dependent QT) → fluvoxamine. BPH with hesitancy and incomplete emptying under a new psychosis → avoid the anticholinergic low-potency agent. BMI 42 with BP 165/120, 4+ edema, and rales under binge eating disorder → avoid lisdexamfetamine (FDA-approved but sympathomimetic) → sertraline. This is your workhorse Evaluate-level pattern.
- AVOID-THIS-DRUG (negative polarity ask): "What medication should be avoided by the prescriber in this case?" / "What maintenance medication should be avoided in this patient due to his recent history?" All options are plausible agents for the stated condition; exactly one is contraindicated by a detail planted earlier. Include at least one negative-polarity item per batch.
- CLONED-STEM VARIABLE SWAP: run the SAME vignette twice with exactly one variable changed, so the answer moves. 27 days of a delusion → brief psychotic disorder; 4 months of the same delusion with functional decline → schizophreniform; about a year → schizophrenia. Or hold the vignette fixed and move the ask: same 23-year-old with cafeteria persecutory delusions asked (a) most likely diagnosis, (b) etiologic pathway of his hallucinations, (c) which drug he was started on given neck spasms 2 days later. Build one such chain per batch. The shared text must be verbatim-identical except the swapped variable — that is what makes the item honest.
- ONE-WORD TIEBREAKER: two syndromes with near-identical surfaces separated by a single exam finding. NMS vs serotonin syndrome: lead-pipe rigidity + diminished reflexes + 1–3 day onset vs hyperreflexia/clonus + <24 hr onset. Waxy flexibility (examiner positions the limb) vs catatonic posturing (patient assumes it) vs catatonic negativism (patient resists). Akathisia vs anxiety vs agitation. Register vs recall vs concentration on MSE.
- FALSE-SOPHISTICATION TRAP: the option that "sounds newer/safer/more advanced" is wrong on the actual data. Switching off haloperidol for akathisia → aripiprazole and cariprazine LOOK like the sophisticated pick but carry some of the highest akathisia rates; olanzapine is the right switch. Adding a second serotonergic agent looks aggressive-and-thorough but raises serotonin syndrome risk. Escalating the antipsychotic dose for akathisia worsens a dose-related effect.
- THERAPY-BEFORE-ESCALATION: after one failed adequate medication trial, the evidence-based next step is often the psychotherapy that was never started (ERP for OCD; in vivo exposure for specific phobia; DBT for borderline PD self-harm), not the third drug. Pair this with dose-sequencing items.
NBOME signature moves (layer onto the same skeleton):
- VISCEROSOMATIC CLUE: segmental hypertonicity used exactly like a lab value (e.g., T2–T4 findings pointing toward a sympathetic/endocrine process behind "panic" symptoms).
- NEGATIVE STRUCTURAL EXAM AS RULE-OUT: a fully described unremarkable structural exam (negative flexion tests, normal ROM, no tender points) actively eliminates the somatic explanation and pushes toward the psychiatric diagnosis.
- NEUROANATOMIC ANSWER SET: a clinical-recognition stem whose options are brain regions, pathways, or neurotransmitter pairs (VTA vs nucleus accumbens vs substantia nigra for the mesolimbic target of antipsychotics; dopamine–acetylcholine imbalance for EPS), with 1–2 distractors worded to sound plausible on vocabulary alone. Prefer the origin-vs-projection distinction as the discriminator.
- FORENSIC / DUE-PROCESS ITEM: criminal responsibility framing, capacity, or medication-over-objection. When the stem says "there are no active safety concerns," every option that forces medication is wrong and the answer is the judicial petition. Stack criteria (ideas of reference + magical thinking + odd beliefs) so the reader must count DSM criteria, not pattern-match one symptom. Include one legal/ethics item per batch when the content supports it.
- IATROGENIC IN PROGRESS: a complication unfolds from treatment already started (5% dextrose in a malnourished drinker → worsening confusion + extraocular dyssynergia); the answer targets the mechanism (add thiamine), not the surface complaint. Also: the movement side effect appearing 48 hours into a new antipsychotic, where the ask is management (propranolol for akathisia; benztropine/diphenhydramine for acute dystonia) rather than diagnosis.
- DURATION ARITHMETIC: durations function as math constraints — a 3-month behavior change tied to a loss 4 months ago rules ODD (≥6 months) out and adjustment disorder in. Give the reader the arithmetic to do ("I haven't left my apartment since March (it is now June)"). Numbers must be internally consistent and decisive on their own.
- FUNCTIONAL-OUTCOME LITERACY: symptom-controlled, adherent, but socially non-functioning patient → the functioning-focused intervention (psychosocial rehabilitation), not another symptom-focused change.

════════ DISTRACTOR ARCHITECTURE ════════
- All options from ONE answer category (all diagnoses, all next steps, all drugs, all brain regions, all neurotransmitter pairs, all counseling statements). Parallel-category rule: wrong answers come from the same family as the correct one, differing by one criterion (duration, precipitant, one defining feature, one receptor).
- Each item includes at minimum: one adjacent-DSM-category distractor (duration-swap or criteria-swap neighbor) and one "surface-read" distractor (what you'd pick using only the chief complaint).
- On 6- and 7-option items, the extra slots must be the tightest neighbors, not the loosest — an EPS set should hold the full movement-disorder family, a psychosis set should hold the full duration ladder (brief psychotic → schizophreniform → schizophrenia → schizoaffective → delusional → schizotypal PD).
- Stem-type must match answer-type: diagnosis→diagnosis; next-step-management→the most conservative/safe/sequential action, not the most aggressive; next-step-diagnosis→a test, never a treatment; pharmacotherapy→a drug; mechanism→a mechanism.
- Management sets may legitimately include a "no pharmacotherapy warranted at this point; psychotherapy only" option — when you use it, it must be genuinely defensible for some reader, and the stem must contain the detail that decides against (or for) it.
- Communication/ethics items follow: acknowledge/validate → assess safety directly → address the patient before third parties (unless minor or lacks capacity) → due process before coercion.
- Counseling-statement items: options are quoted sentences a physician might say ("You may need to be patient with the medication, as you may not feel its effects right away"), each mapping to a DIFFERENT drug class's counseling point (MAOI tyramine, SGA metabolic, TCA lethality-in-overdose, dystonia). The reader must first infer the class, then pick its counseling point.
- All distractors must remain plausible to a reader who missed the buried clue.

════════ BATCH BLUEPRINT ════════
Across the batch, mix item types roughly as: 35–45% most-likely-diagnosis, 15–20% next-step management, 15–20% pharmacotherapy (including at least one AVOID/contraindication item, at least one EFFECT→AGENT reverse ID, at least one adverse-effect-of-inferred-drug item, and — when the content supports it — one dose-sequencing item), 10–15% mechanism/neuroanatomic/receptor-pharmacology correlate or lab-workup, 5–10% MSE-terminology or one-line applied concept, and 1 communication/ethics/legal item when the content touches patient interaction or involuntary treatment. Layer in the compact-narrative, one-line, sentence-completion, and recall shapes from ITEM FORMAT VARIETY.
Build one 2–3 question chain per batch off the same clinical stem (presentation → diagnosis → mechanism/treatment/complication), or one CLONED-STEM VARIABLE SWAP pair.
Do not use the same correct diagnosis more than twice per batch.
DIFFICULTY DIAL — in at least 5 of 15 items, the correct answer must NOT be the single most famous association for that presentation; it must be the second-order pick forced by a stated constraint or by real comparative data (fluvoxamine over citalopram/clomipramine with AV block; olanzapine over aripiprazole for akathisia; sertraline over lisdexamfetamine in decompensated BED; ziprasidone over risperidone when EPS is the patient's stated fear; ERP over a medication switch after one failed SSRI; clozapine despite an existing LAI when suicidality is the target). Tag these Analyze or Evaluate.
Run the BLOOM TALLY and the ANSWER BALANCE CHECK below before output — do not eyeball either.

════════ ANSWER BALANCE CHECK (mandatory, run after drafting all items, before output) ════════
1. List every item's correct letter in the order the items appear (e.g., C, A, D, B, E, C, A, ...).
2. Tally the totals per letter. Target for 5-option items: each of A–E correct 2–4 times in a 15-item batch (count ÷ 5, ±1). Items with 6–7 options participate in the same tally; F and G are legitimate answer slots and at least one correct answer per batch should sit in an F or G slot when 6–7-option items are present, so those slots aren't dead giveaways.
3. Check for streaks: the same letter should not be correct for 3 consecutive items even if the raw tally is balanced.
4. Fix any imbalance or streak by reordering the CHOICE LIST for specific items (move the correct option to a different letter slot and reshuffle the distractors around it) — never by changing which option is medically correct, and never by wording an option to sound more/less correct because of its position. When options have a natural order (alphabetical drug lists, a duration ladder), keeping that order is fine — real exams do — so fix imbalance on the items that have no natural order first.
5. Re-tally after adjusting and repeat until both checks pass.
6. Then run the BLOOM TALLY: list each item's Bloom level in order, count them, and confirm the batch hits the target mix and the hard floor of ≥6 Analyze/Evaluate items. Fix by deepening weak items, never by relabeling them. Only then produce the final JSON.

════════ EXPLANATION CRAFT (calibrated from the source banks — match this register) ════════
"explanation" (3–6 sentences):
- Open by naming the diagnosis or agent and the specific findings that establish it, restating the buried clue in criteria language ("At 27 days — just under the one-month mark — with a delusion plus odd speech, this fits Brief Psychotic Disorder: ≥1 core psychotic symptom for 1 day to <1 month...").
- Show mechanism with arrows where one exists: "Striatal D2 blockade → dopamine–acetylcholine imbalance toward relative cholinergic excess → EPS including akathisia."
- Name the trap out loud when the item has one: "It's a common trap to assume the dopamine partial agonists are the 'safest' switch — in reality they carry some of the highest reported akathisia rates."
- Close with one board pearl the student can carry: the monitoring schedule, the FDA indication, the trial name, the dose ceiling, the reason it's never rechallenged.
- Never write "the other options are incorrect."
"wrongExplanations" (1–2 sentences each): name the SPECIFIC criterion, duration threshold, receptor, or mechanism that fails — never a bare denial. Good: "Schizophreniform disorder requires symptoms lasting 1 to 6 months — at 27 days, she hasn't reached that threshold yet." "Benztropine is the classic choice for acute dystonia and drug-induced parkinsonism, but it's a less reliable treatment for akathisia specifically than a beta-blocker." Bad: "This is not the correct diagnosis." When a distractor is a defensible-but-inferior choice, say so and say why it loses ("Cross-tapering to clomipramine is reasonable for SSRI-refractory OCD, but it isn't prioritized ahead of ERP, which is often overlooked and effective on its own or combined with medication").
"eli5" (max 3 sentences): plain words a 10-year-old knows, reusing the concrete image from the stem (the dog, the ball, the motor that won't turn off). No drug classes by mechanism name unless immediately unpacked. Good: "When someone moves your arm and you just leave it there, that's called waxy flexibility — it's one of the classic signs doctors look for in catatonia."

════════ WORKED EXEMPLARS (style reference ONLY — never reuse their content) ════════
EXEMPLAR 1 — NBME profile, Analyze (second-workup trap):
"A 68-year-old man is brought to the physician by his daughter because of a 5-day history of talking to people who are not present and accusing staff at his assisted-living facility of stealing his mail. His daughter says he was 'his usual sharp self' at a family dinner 1 week ago. He has hypertension treated with lisinopril. He has no history of psychiatric illness. His temperature is 37.9°C (100.2°F), pulse is 96/min, and blood pressure is 138/84 mm Hg. Physical examination shows mild suprapubic tenderness; there are no focal neurologic findings. On mental status examination, he is oriented to person but not to place or time, and his attention waxes and wanes during the interview. Which of the following is the most appropriate next step in diagnosis?"
Options: A. Head CT / B. Lumbar puncture / C. Serum TSH level / D. Urinalysis / E. EEG. Correct: D. Bloom: Analyze.
Architecture: buried clue = low-grade fever + suprapubic tenderness + acute change from a documented 1-week-ago baseline; dramatic decoy = paranoid accusations and hallucinations tempt a primary-psychosis or dementia workup; waxing-waning attention in the MSE is the delirium tiebreaker; "no history of psychiatric illness" rules out the psychosis option; all five options are diagnostic workups (stem-type match).

EXEMPLAR 2 — NBOME profile, Analyze (inline ask, duration arithmetic):
"An 11-year-old girl is referred to the office by her school because of a 2-month history of arguing with teachers and refusing to complete assignments. Notes from her teacher state that she was previously a cooperative, high-performing student. She denies problems with sleep, and her appetite is intact. She has never been cruel to animals, destroyed property, or stolen. Her parents finalized their divorce 3 months ago. On examination she sits still and answers questions in a low voice, blaming her teachers for the conflicts. The most likely diagnosis is"
Options: A. adjustment disorder / B. attention-deficit/hyperactivity disorder / C. conduct disorder / D. major depressive disorder / E. oppositional defiant disorder. Correct: A. Bloom: Analyze.
Architecture: duration arithmetic is the buried clue — 2 months of symptoms beginning within 3 months of an identifiable stressor fits adjustment disorder, while ODD requires ≥6 months; the decoy = arguing/defiance surface-reads as ODD; the explicit negatives (no cruelty, destruction, theft; sleep and appetite intact) each rule out one listed option; the previously-well-behaved baseline blocks ADHD; the ask is folded into the final sentence per NBOME style.

EXEMPLAR 3 — compact narrative + paired recall, Apply + Remember:
"Lucy is a 32-year-old woman who lives alone on welfare in a small apartment. She has no apparent friends. Her neighbors consider her peculiar, and the neighborhood children often tease her about her appearance. Lucy's clothes appear slightly askew, and her makeup is unusual. She is generally suspicious of other people and often makes strange gestures when she passes people in the street. Her social worker reports that Lucy is always anxious during their meetings and has a very limited range of emotional expression, accompanied by unusual beliefs that she has special telepathic powers. Which of the following personality disorders is most likely?"
Options: A. Avoidant / B. Borderline / C. Schizotypal / D. Schizoid / E. Paranoid. Correct: C. Bloom: Apply.
Architecture: no clinical encounter framing at all — third-person descriptive voice; the cluster of odd behavior + odd beliefs (magical thinking) + constricted affect + social anxiety is the whole clue, distributed across the paragraph; distractors are adjacent Cluster A/B/C disorders that each explain only part of the picture (Schizoid = no odd beliefs; Paranoid = no magical thinking; Avoidant = wants friends and lacks odd beliefs).
Paired RECALL item (no patient at all): "Which of the following personality disorders is most common in the biological relatives of patients with schizophrenia?" A. Schizoid / B. Paranoid / C. Schizotypal / D. Histrionic / E. Antisocial. Correct: C. Bloom: Remember.

EXEMPLAR 4 — COURSE-EXAM profile, 6 options, Evaluate (comorbidity-as-constraint + avoid-polarity):
"A 50-year-old man presents to a family medicine clinic after not seeing a physician in 25 years. He has recently begun having difficulty urinating, is up many times throughout the night to go to the bathroom, and has trouble starting and stopping his stream. He often feels he does not empty his bladder. On further questioning he states that he has heard voices since his 20s telling him to be afraid of doctors, which is why he had not been seen in so long. He also states that physicians steal their patients' genetic information and sell it to the government. Mental status examination is significant for slow speech, incongruent mood, and flat affect. Medical causes of his psychotic symptoms are ruled out and a psychiatric diagnosis is made. What medication should be avoided by the prescriber in this case?"
Options: A. Aripiprazole / B. Chlorpromazine / C. Fluphenazine / D. Haloperidol / E. Olanzapine / F. Risperidone. Correct: B. Bloom: Evaluate.
Architecture: the psychiatric picture (chronic hallucinations + persecutory delusions + negative symptoms) is entirely scenery — every option treats it; the decoy is the temptation to rank options by EPS risk; the buried clue is the BPH obstructive picture in the opening lines, which makes the strongly anticholinergic low-potency agent the one to avoid. Negative-polarity ask, terse course voice, 6 options because the whole antipsychotic family belongs in the set.

EXEMPLAR 5 — COURSE-EXAM profile, Analyze (double-hop, no drug named):
"A 22-year-old street performer comes to the clinic because he is unable to perform. He says that right before he begins his musical act he experiences fluttering in his chest, shortness of breath, and diaphoresis. He has no symptoms in any other setting, no medical history, and takes no medications. Vital signs and physical examination in clinic are normal. What is the most likely side effect of the most likely prescribed medication?"
Options: A. Nausea and GI upset / B. Agitation / C. Suicidal ideation / D. Insomnia / E. Bradycardia. Correct: E. Bloom: Analyze.
Architecture: two hops with the middle step unnamed — performance-only anxiety → propranolol as the situational agent of choice → bradycardia as its effect. The decoys are all SSRI side effects, which is what a reader picks after one hop instead of two ("anxiety → SSRI"). "No symptoms in any other setting" is the negative that rules out generalized social anxiety disorder and therefore rules out the SSRI path.

════════ QUALITY GATE — run silently on every item before output ════════
Structure (full-vignette items only): opening line complete · exact duration present · behavioral wording · ≥1 explicit negative · MSE near the end. Compact-narrative/one-line/sentence-completion/recall items are exempt from this row by design.
Trap (full-vignette items only): exactly one buried clue · one separate dramatic decoy · every negative rules out a listed option.
Options (every item, every format): parallel category · ≥1 same-family distractor · all plausible without the clue · mutually exclusive · exactly one unambiguously correct · no length bias · 4–7 options with the extras earning their slot · passes the ANSWER BALANCE CHECK.
Match: stem type = answer type · management answers are conservative-first · communication items follow the hierarchy · legal items respect due process when no emergency is stated · NBOME items use structural findings correctly (confirmatory or rule-out, never decorative) and internally consistent duration math.
Bloom: the declared level matches the actual cognitive demand · batch hits the target mix and the ≥6 Analyze/Evaluate floor.
Explanations: correct explanation names diagnosis + clue + mechanism + trap + pearl · every wrongExplanation names a specific failed criterion · eli5 ≤3 sentences and jargon-free.
If an item fails after 2–3 silent revisions, drop it and write a replacement. Never ship a failing item and never show the checklist.

Professor-voice notes: clipped exam findings, subtle pattern-recognition clues, no giveaway wording, occasional grounded real-world detail (a specific dollar amount lost gambling, a named campus, a stuffed animal revealed on video visit, a ball tossed to a "blind" patient). When the source emphasizes them, lean on: UMN/LMN/NMJ/myopathy localization, exact genetics (chromosome, repeat, gene), Circle-of-Willis vascular localization, mechanism-of-injury nerve/plexus localization, CSF profile patterns, vignette-to-histopathology pairing. Reuse heavily-emphasized concepts with fresh vignette surfaces.

════════ ANTI-PATTERNS — never do these ════════
- Diagnostic label language in the stem ("appears depressed," "has hallucinations" is fine in MSE; "is clearly manic" is not).
- Teaching in the stem ("classic for," "pathognomonic," "which is characteristic of").
- Vignettes under 55 words in course profile / under 60 in NBME profile, or "A patient with schizophrenia..." pseudo-stems.
- Mixed-category option sets (a drug hiding among diagnoses).
- "All/none of the above," compound options ("A and C").
- Correct answer uniquely longest, uniquely shortest, most technical-sounding, or most hedged. On next-step items, watch the reverse bias too: don't let the correct answer be the only option without a tacked-on "...and discharge."
- Vague durations ("recently," "for a while," "several weeks").
- Negatives that don't rule out a listed option.
- Padding to 6 or 7 options with implausible filler.
- Declaring a Bloom level the item doesn't earn.
- Two defensible answers. If a diagnosis is genuinely borderline, revise the stem until exactly one answer is unambiguous. If the source material itself contains an item with two defensible answers, fix it rather than reproducing the ambiguity.
